# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: open this repository's **Security** tab and choose **Report a vulnerability**. Include what you found, how to reproduce it and which package it affects (`tabletop-server`, `tabletop-client` or `initiative-tracker`).

## What to expect

- We aim to acknowledge a report within 3 working days and to tell you what we plan to do within 14 days.
- We will credit you in the fix notes if you want that.
- This is a volunteer-run project, so there is no bug bounty.

## Supported versions

Only the latest release and the `main` branch receive security fixes.

## Scope

The code in this repository. If you self-host, keep your dependencies updated and put the websocket server behind your own authentication hook.
